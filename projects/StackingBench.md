Vibe coded & Works on my machine.

LLM の盤面理解、先読み、攻防判断を比較・記録するローカル対戦環境です。
SRS の到達可能な配置から1個ずつ選択し、7固定ごとに交代します。

OpenAI 互換 API の LLM のほかに、Codex や Antigravity CLI (agy)、TypeSafe Jev などを対戦させることもでき、
評価用に探索 bot や人間による手動操作も選択できます。

詳細については [README](https://github.com/Rinrin0413/StackingBench/blob/main/README.md) を参照されたし。
